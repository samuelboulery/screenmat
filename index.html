How it works

Three moves, no settings to learn.

  1. 01 · ⌘V

    Paste

    A screenshot, or a folder of them. The background is drawn from its own dominant colours, so it looks right before you touch anything.

  2. 02 · T A R B

    Adjust

    Frame, corners, tilt. Text, arrows, boxes, numbered badges. Blur what should stay private — it is baked into the pixels, not laid on top.

  3. 03 · ⌘E

    Export

    WebP or PNG at 1×, 2× or 3× — up to 4800 px wide. A whole batch leaves as one zip, every image in the same style.

Privacy

Your screenshot never leaves this tab.

  • No upload. Every pixel is drawn by Canvas 2D in your browser.
  • No account. Styles and history live in this browser's storage.
  • Works offline. Fonts are bundled; nothing is fetched to render.
  • One counter. A cookieless page count from Cloudflare — no identifier, no image data.
Developers

The same engine, from a script.

A CLI for build scripts, a Node API for docs generators, an MCP server for agents. One renderer behind all three — the exact one this page just used. Tune a style by eye here, export it as JSON, call it by name there.

# CLI
pnpm cli screenshot.png --frame macbook --ratio 16:9 --scale 3

# MCP — any client
claude mcp add screenmat -- node /path/to/screenmat/cli/mcp.ts

# Node
import { render } from 'screenmat/node'
await render({ input: 'shot.png', style: 'docs' })
